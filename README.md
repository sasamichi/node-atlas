# Node Atlas（ノード・アトラス）

世界の交通網・国と地域・気候のデータを集め、変遷と繋がりをたどる個人プロジェクトの公開サイトです。

- サイト： https://sasamichi.github.io/node-atlas/
- 収録データ：国 250 件・地域 5,045 件（ISO 3166-1 / 3166-2 の一覧が土台）、函館本線の拠点 90 件・区間 90 件
- 出典：公式リストが入手・利用できる場合はそれを優先し、ない場合は Wikipedia／Wikidata と他の Web 百科事典。文章の転載はせず、事実データのみを抽出しています（Wikipedia は CC BY-SA）。
- 地域の一覧には、出典リストの時点の情報で最近の再編が反映されていないものや、確認中の項目が含まれます。確認中の項目はサイト上で「（要確認）」と表示しています。

このリポジトリは公開用のコピーです。収集データの正本はプロジェクトの収集シート（Google Sheets）で管理しています。
